## Deploy

### Option 1 — Vercel (one click)

1. Push this repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repo → Framework: **Other** → Deploy

### Option 2 — Vercel CLI

```bash
npm i -g vercel
vercel        # preview
vercel --prod # production
```

### Option 3 — Any static host

This is plain HTML. Drag `index.html` into Netlify, Cloudflare Pages, GitHub Pages, S3, or any static host.

## Customization

To rebrand for a different clinic:

1. Open `index.html`
2. Find & replace clinic name, doctor name, services, contact details
3. Update the WhatsApp / call CTAs with the new number
4. Push → auto-deploys
